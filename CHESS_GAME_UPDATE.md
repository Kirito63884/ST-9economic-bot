# Шахматы

`chess_game.py` хранит ходовую историю и проверяет все ходы на сервере через `python-chess` (зависимость `chess==1.11.2`). Библиотека распространяется по GPL-3.0-or-later ([PyPI, chess 1.11.2](https://pypi.org/project/chess/1.11.2/)); серверный запуск не передаёт исполняемый код игрокам. При распространении сборки сохраняйте текст лицензии и соблюдайте её условия. Версия зафиксирована и используется в целевом Python 3.12 окружении проекта; библиотека — pure Python, дополнительных системных движков не требует. Остальные зависимости не обновляются. Используются только обычные шахматы, без вариантов и шахматных часов.

`chess_routes.py` создаёт стол, приглашает по ссылке, принимает игроков, фиксирует готовность и списывает/возвращает взносы в общей транзакции runtime. При взносе 0 игра бесплатная. Выигрыш получает победитель, согласованная/правильная ничья возвращает взносы; незавершённая партия возвращает взносы после 8 часов без успешных действий игроков. Опрашивание состояния не обновляет срок. Успешный ход, готовность, присоединение, предложение/принятие ничьей или выход являются действиями игрока.

Ничья по трёхкратному повторению позиции и правилу 50 ходов заявляется игроком, чей ход; пятикратное повторение, правило 75 ходов, пат и недостаточный материал завершают игру автоматически. Недостаточность определяется правилами библиотеки `python-chess`. Позиция вместе с UCI историей ходов сохраняется в существующем `app_runtime`; миграции базы нет.

Установка после объединения PR: получить полный SHA, сохранить проверенную резервную копию и применить `scripts/update_chess_game.sh <SHA> [каталог-приложения]`. Скрипт проверяет состав архива, устанавливает закреплённую библиотеку в venv сайта, проверяет импорты и перезапускает только `balance-app.service`. Он не устанавливает обновление автоматически из PR.

Ограничение первого выпуска: нет шахматных часов и рематча за тем же столом; после завершения игроки выходят в лобби и создают новую партию. Интерфейс использует Unicode фигуры без внешних изображений.
