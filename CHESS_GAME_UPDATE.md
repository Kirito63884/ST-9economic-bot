# Шахматы

`chess_game.py` хранит ходовую историю и проверяет все ходы на сервере через `python-chess` (зависимость `chess==1.11.2`). Библиотека распространяется по GPL-3.0-or-later ([PyPI, chess 1.11.2](https://pypi.org/project/chess/1.11.2/)); серверный запуск не передаёт исполняемый код игрокам. При распространении сборки сохраняйте текст лицензии и соблюдайте её условия. Версия зафиксирована и используется в целевом Python 3.12 окружении проекта; библиотека — pure Python, дополнительных системных движков не требует. Остальные зависимости не обновляются. Используются только обычные шахматы, без вариантов и шахматных часов.

`chess_routes.py` создаёт стол, приглашает по ссылке, принимает игроков, фиксирует готовность и списывает/возвращает взносы в общей транзакции runtime. При взносе 0 игра бесплатная. Выигрыш получает победитель, согласованная/правильная ничья возвращает взносы; незавершённая партия возвращает взносы после 8 часов без успешных действий игроков. Опрашивание состояния не обновляет срок. Успешный ход, готовность, присоединение, предложение/принятие ничьей или выход являются действиями игрока.

Ничья по трёхкратному повторению позиции и правилу 50 ходов заявляется игроком, чей ход; пятикратное повторение, правило 75 ходов, пат и недостаточный материал завершают игру автоматически. Недостаточность определяется правилами библиотеки `python-chess`. Позиция вместе с UCI историей ходов сохраняется в существующем `app_runtime`; миграции базы нет.

Совместимость с морским боем: общие runtime, меню, избранное, журнал, срок
неактивности и управление столами сохраняют обе игры. Дополнительные HTTP-тесты
проверяют одновременные столы, повторы и CSRF, изменение баланса перед стартом,
ничью и откат матующего хода при невозможной выплате.

Установка после объединения PR: получить полный SHA, сохранить проверенную резервную копию и применить `scripts/update_chess_game.sh <SHA> [каталог-приложения]`. Скрипт проверяет состав архива и зависимые локальные модули, делает приватную
копию файлов и согласованную SQLite-копию с quick_check, проверяет сохранение
ключей уже установленных игр. В комплект входят модули/шаблоны морского боя,
чтобы первое добавление двух игр не создавало циклическую зависимость установщиков.
Затем устанавливается только chess==1.11.2 без обновления других зависимостей.
Импорт main проверяется без запуска фоновых задач. При ошибке возвращается
прежний код; рабочая БД поверх новых записей других процессов не восстанавливается.
Обычно перезапускается только balance-app.service; бот дополнительно — лишь
если ещё не установлена прежняя политика сборов. Сборщики не перезапускаются. Он не устанавливает обновление автоматически из PR.

Ограничение первого выпуска: нет шахматных часов и рематча за тем же столом; после завершения игроки выходят в лобби и создают новую партию. Интерфейс использует Unicode фигуры без внешних изображений.

Браузерная проверка: `python scripts/check_chess_browser.py --app-python .venv/bin/python`.
Она использует локальный изолированный fixture-runner морского боя. Проверены две
сессии, мышь и реальное касание, ориентация доски, сохранение позиции после
перезагрузки, согласованная ничья с возвратом и выход. Одинаковый опрос состояния
не заменяет DOM клеток, сохраняя фокус и касание. Playwright нужен только для
разработки, внешние запросы браузера блокируются.

Для общего выпуска шахмат, моделей морского боя и техадмина используйте
`scripts/update_games_and_access.sh FULL_COMMIT_SHA /var/www/balance-app`.
Прежние три точки установки перенаправляют в этот единый проверенный комплект,
чтобы общий main, модели пользователей, JS-partials и зависимости совпадали.
Подробнее: [GAMES_ACCESS_UPDATE.md](GAMES_ACCESS_UPDATE.md).

Исправление доски: клетки имеют восемь явных равных строк/столбцов и не
растягиваются по высоте боковой панели. Координаты a–h / 1–8 показаны с четырёх
сторон и перевёрнуты для чёрных; ориентация сохраняется от ожидания до старта.
Точка обозначает обычный ход, кольцо — взятие (включая взятие на проходе).
Кнопки клеток сохраняются при выборе/опросе, работают стрелки, Enter и Escape.
Ответ старого опроса после действия не возвращает прежнюю позицию. Выход из
незавершённой партии и сдача требуют подтверждения с пояснением о поражении.
Общее обновление интерфейсов: `scripts/update_game_boards.sh`, GAME_BOARDS_UPDATE.md.
