# Вход в Protocol из админки

Владелец, технические и главные администраторы открывают **Админка → Загрузка
статистики → Вход в Protocol**. На игровом сервере Protocol нужно написать `!сайт`,
получить шестизначный код и ввести его в форму. Пароль Steam не нужен.

Используется тот же вход и файл `PROTOCOL_COOKIE_FILE`, что у `protocol_login.py`.
Сначала проверяется доступ к составу клана; только после успеха сессия атомарно
сохраняется с правами 0600. Ошибка входа не заменяет прежнюю сессию. Сборщик прочитает
новую сессию в очередном цикле, перезапускать его не требуется. Успешный вход обновляет
доступные данные состава и снимает прежнюю задержку повторной проверки выгрузок.

Код передаётся POST-запросом, очищается из поля сразу после отправки и не сохраняется
в базе, журнале, URL или browser storage. Сессия не возвращается браузеру. API проверяет
вход, актуальные права и версию сессии, CSRF и origin. Права повторно проверяются
перед сохранением файла. Вход выполняется вне блокировки кошелька; файловая блокировка
сериализует веб-вход между процессами, интервал между попытками — 30 секунд.
Старшие/младшие администраторы и обычные игроки не могут менять эту общую сессию.

Если вход успешен, а обновление статистики завершилось ошибкой, интерфейс сообщает
об этом отдельно: новый одноразовый код для уже сохранённой сессии не нужен.

## Установка после объединения PR

Полный SHA берётся из согласованного `main`. На сервере от root:

```bash
bash <<'BASH'
set -euo pipefail
umask 077
revision=ВСТАВЬТЕ_ПОЛНЫЙ_SHA_ИЗ_MAIN
installer=$(mktemp /tmp/protocol-web-install.XXXXXX)
trap 'rm -f "$installer"' EXIT
curl -fL --max-time 60 \
  "https://raw.githubusercontent.com/Kirito63884/ST-9economic-bot/$revision/scripts/update_protocol_web_login.sh" \
  -o "$installer"
bash "$installer" "$revision" /var/www/balance-app
BASH
```

Установщик создаёт проверенную копию файлов и SQLite, добавляет форму и маршруты
в установленные `main.py`/шаблон, сохраняя другие игры и вкладки. Незнакомый формат
общих файлов останавливает установку до перезапуска. Схема базы не меняется.
Перезапускается только `balance-app.service`; при ошибке восстанавливаются файлы,
рабочая база и сессия Protocol не заменяются резервной копией.

Проверки выполняются с вымышленными пользователями и HTTP-подменой Protocol:
`tests/test_protocol_web_login.py`, существующие проверки `test_protocol_clan.py`,
проверка патча установщика и `scripts/check_protocol_login_browser.py` (Chromium,
компьютер/телефон). Настоящий код в процессе разработки не запрашивался, вход на
рабочем сервере ещё не выполнялся. После установки обновите админку Ctrl+F5 и
проверьте свежим кодом из игры; код и cookies не отправляйте в чат.

Фактический результат подготовки: полный `bash scripts/check.sh` — 743 passed;
браузерная проверка 1440/390 px прошла. На временной установке проверены успешное
копирование и откат при ошибках копирования/HTTP; патч общих файлов проверен на
повторное применение, сохранение существующих дополнений и отказ при неизвестной
структуре. Рабочий сервер не изменялся.
