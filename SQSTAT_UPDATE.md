# SQSTAT: переезд на prot.sqstat.ru

На сервере подтверждён ответ `HTTP 301` от `https://prot.p.sqstat.ru/` с
`Location: https://prot.sqstat.ru/`. Загрузчик безопасно отклонял переадресацию
до чтения списка матчей, сохраняя прежние данные и дату успешной проверки.

Обновление направляет запросы сразу на `https://prot.sqstat.ru`. Служебная
cookie PHPSESID также принадлежит новому домену. Автоматические переадресации
по-прежнему запрещены, каждый запрос и повтор проходят общий ограничитель
частоты: не чаще одного запроса в 60 секунд.

Новые недельные агрегаты записывают новый источник. Проверенные старые
агрегаты со старым адресом сохраняют силу; принимаются только два точных
HTTPS-источника. Пересоздание базы, удаление статистики или перезапись
доказательств ранее выданных наград не требуются. Ссылки на матчи на сайте
ведут на новый адрес. Составы Discord и назначения ролей не меняются.

## Установка

Для существующей установки передайте установщику третий аргумент
`sqstat-source`: `bash installer.sh COMMIT_SHA /var/www/balance-app sqstat-source`.
Режим заменяет пять файлов: `medals_source.py`, `medals_monitor.py`, `medals.py`,
`squad_play_history.py`, `templates/admin.html`. Он сохраняет резервную копию,
перезапускает только `balance-app.service` и `balance-app-medals.service` и
проверяет локальный HTTP. При ошибке запуска восстанавливает прежние файлы.
Discord-бот, база, `.env`, cookies Protocol и другие настройки не заменяются.

Сборщик сначала проверяет профили, затем архив. При большом числе участников
и матчей полный цикл может занять длительное время из-за ограничения частоты.
Не запускайте дополнительный ручной сбор параллельно службе. Поле
`checked_at` обновится после успешного прохода архива; до этого старая дата
сама по себе не показывает прогресс нового сканирования.

Без раскрытия приватных параметров прогресс можно посмотреть так:

```bash
cd /var/www/balance-app
runuser -u www-data -- ./venv/bin/python - <<'PY'
import json
from database import SessionLocal
from medals import MedalMonitor
with SessionLocal() as db:
    row = db.get(MedalMonitor, 1)
    data = json.loads(row.payload) if row else {}
    print("Последняя запись состояния (UTC):", row.updated_at if row else None)
    for key in ("status", "phase", "profiles_done", "profiles_total", "profiles_failed", "current_match", "checked_at", "last_error"):
        print(f"{key}: {data.get(key)}")
PY
```

Сам HTTP-переезд подтверждён диагностикой пользователя. Реальное успешное
чтение новых страниц и окончание цикла проверяются после установки на сервере.
