# Длинные и короткие нарды

Два игрока, вариант выбирается при создании стола. Игра доступна в «Игры → Нарды»,
в общей навигации и как любимая игра профиля. Открытый или закрытый стол, приглашение
по ссылке, готовность обоих, следующая партия, выход и расформирование свободного
стола. Тёмная доска с 24 пронумерованными пунктами, шашками двух цветов, баром,
счётчиками выброса, костями, подсветкой и журналом. Мышь и касание работают одинаково:
выбрать шашку, затем пункт; при неоднозначном выбросе выбрать конкретную кость.

## Принятые правила и источники

Короткие нарды: [правила Backgammon Galore / Tom Keith в руководстве GNU Backgammon](https://github.com/mormegil-cz/gnubg/blob/master/doc/gnubg/gnubg.texi),
раздел Rules of the game. Длинные: сопоставлены реализации и пояснения
[LongBackgammon](https://github.com/ansribas/LongBackgammon),
[Long_Backgammon_Narde](https://github.com/Thereal-Vadim/Long_Backgammon_Narde)
и [scriptum/backgammon](https://github.com/scriptum/backgammon).
Это ссылки на материалы проверки; приложение не загружает их при игре.
Движок проекта написан отдельно, новых серверных зависимостей нет.

Общие правила:

- По 15 шашек. Жеребьёвка по одной кости; равные значения перебрасываются.
  В коротких победитель использует обе кости жеребьёвки; в длинных бросает новую пару.
- Каждая кость — отдельное перемещение, включая проверку промежуточных пунктов;
  дубль используется четырежды. Кости генерирует `secrets` на сервере.
- Обязательно максимальное число используемых костей. Если можно сыграть только
  одну из двух разных костей, используется большая. Разрешены только такие первые
  перемещения, после которых это требование ещё можно выполнить.
- Выброс — когда все оставшиеся шашки в своём доме и бар пуст. Точная кость либо
  большая с самой дальней оставшейся шашки, если дальше своих нет. Допустимы ходы
  внутри дома вместо выброса, с сохранением обязательного использования костей.
- Первый снявший все шашки победил. Выход/сдача во время игры означает поражение.

Длинные: оба цвета идут в одном направлении; головы на противоположных пунктах,
по 15 шашек. С головы одна шашка за ход, на первом личном ходу при 3:3, 4:4 и 6:6
допустимы две. На любую шашку соперника вставать нельзя, сбивания и бара нет.
Шесть занятых подряд пунктов запрещены, если за ними по маршруту противника нет
его шашек и он ещё не начал выброс. Маршрут заканчивается выбросом и не соединяется
снова с собственной головой. «Оин» и «марс» различаются по тому, начал ли проигравший
выбрасывать; отдельный вариант «домашнего марса» не вводится.

Короткие: стандартная расстановка 2–5–3–5 и встречное движение. Две шашки противника
закрывают пункт, одна сбивается на бар. Вход с бара обязателен прежде остальных
перемещений. Если вход закрыт, используются только возможные кости, остальные
теряются. Обычная победа, марс/гэммон и кокс/бэкгэммон определяются по выброшенным
шашкам проигравшего и их наличию на баре/в доме победителя.

Это отдельная партия с фиксированным взносом, без куба удвоения, матча на очки
и правила Кроуфорда. Марс/кокс показываются в результате, а не умножают деньги.

## Деньги, безопасность и восстановление

Взнос 0–1 000 000 БК, в целых копейках. Он равен у обоих и не превышает меньший
баланс участников; при старте баланс и доступное место под возможный выигрыш
перепроверяются в той же транзакции. Отрицательный баланс не допускается.
Весь банк получает победитель без комиссии. Очередная партия требует готовности
обоих заново. Состояние, кошелёк и история БК сохраняются общим runtime атомарно.

API не принимает кости, победителя, банк или произвольную расстановку от клиента.
Проверяются сессия, CSRF, членство, очередь и `revision`. Перезапуск воспроизводит
кости и ходы из сохранённой истории; изменённая позиция не принимается.
Кэш хранит только точные проверенные снимки, а восстанавливается независимая копия.
Закрытые столы не появляются у посторонних в списке, а публичная активность не
раскрывает их ID или ссылку. Имена выводятся как текст/с экранированием.

Через 8 часов без успешных действий участников незавершённые взносы возвращаются
однократно, стол удаляется. GET-опрос не продлевает срок. Завершённая партия
сохраняет выплату. Активный стол нельзя удалить через административный API.

## Проверка в отдельной среде

```bash
. .venv/bin/activate
bash scripts/check.sh
python scripts/check_backgammon_browser.py --app-python .venv/bin/python \
  --chromium /usr/bin/chromium --screenshot-dir /tmp/backgammon-screens
```

Playwright нужен только разработчику, не серверу. Browser-runner создаёт отдельную
временную БД, вымышленные аккаунты и cookies, выключает фоновые интеграции и
блокирует внешние запросы браузера. Проверяются обе реальные сессии, готовность,
броски, ходы, сохранение выбора при опросе, телефон, выплата, повторная партия и
расформирование. Для независимого сравнения коротких нард можно скачать только
в рабочую папку разработчика
[`gym_backgammon/envs/backgammon.py`](https://raw.githubusercontent.com/dellalibera/gym-backgammon/master/gym_backgammon/envs/backgammon.py)
и передать локальный путь:

```bash
python scripts/check_backgammon_reference.py /tmp/backgammon-reference.py
```

Сравниваются множества **всех** итоговых позиций полного легального хода, а не только
выбранные случайные перемещения. Эталон не добавляется в зависимости приложения.

## Установка владельцем после объединения PR

Нужен полный SHA согласованного коммита из `main`, включающего другие уже принятые
игры. Сам push ветки не обновляет сервер. На сервере от root:

```bash
bash <<'BASH'
set -euo pipefail
umask 077
revision=ВСТАВЬТЕ_ПОЛНЫЙ_SHA_ИЗ_MAIN
installer=$(mktemp /tmp/backgammon-update.XXXXXX)
trap 'rm -f "$installer"' EXIT
curl -fL --max-time 60 \
  "https://raw.githubusercontent.com/Kirito63884/ST-9economic-bot/$revision/scripts/update_backgammon.sh" \
  -o "$installer"
bash "$installer" "$revision" /var/www/balance-app
BASH
```

Общий установщик проверяет комплект модулей и Jinja-включений, делает приватную
проверенную копию файлов и SQLite-базы. Проверка ключей runtime запрещает установку
коммита, который потерял бы уже установленные игры. Если она сработала, сначала
нужно объединить соответствующие PR и выбрать согласованный SHA, не убирать защиту.

Секреты и рабочие данные не копируются из архива. Новая схема БД не нужна.
Проверяются импорт приложения, восстановление партий и шаблоны. Обычно перезапускается
только сайт; Discord-бот также перезапускается, если изменились общие модели или
политика сборов. Сборщики SQSTAT и игрового онлайна не перезапускаются. Ошибка
возвращает прежние файлы и удаляет новые; рабочая БД поверх новых записей не заменяется.

После установки: HTTP на `http://127.0.0.1:8000/`, журнал `balance-app.service`,
Ctrl+F5 → Нарды. Проверить бесплатную партию двумя аккаунтами, бросок/движение,
перезагрузку, сдачу и следующую партию. При проверке взноса убедиться в двух равных
списаниях и одной выплате всего банка. Проверка настоящего сервера — отдельный шаг.
