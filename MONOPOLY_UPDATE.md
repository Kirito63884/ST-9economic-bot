# Классическая «Монополия» на 2–10 игроков

Добавлена отдельная игра `/games/monopoly/lobby`: тёмное поле из 40 клеток,
цветные фишки, карточки участков, торги и сделки. На узком экране клетки
обозначены номерами: нажатие открывает полные условия. Названия улиц —
русская транскрипция классического поля Atlantic City. Чужие графические
материалы и игровые библиотеки не добавлялись.

## Правила

Используется современный классический вариант с фиксированными налогами
200 и 100. Число мест расширено до 10 по запросу владельца; обычная коробочная
версия рассчитана на меньшее число игроков. Краткая памятка включена в лобби
и на столе. В игре есть:

- 1500 игровых денег у каждого, премия 200 за Старт, выбор первого игрока
  бросками с перебросом равенства, порядок мест и повторный ход после дубля;
- покупка и обязательный аукцион при отказе; все участники, включая
  отказавшегося и заключённых, могут торговаться;
- полные цветовые районы, двойная базовая рента, станции и предприятия;
- равномерное строительство/продажа, 32 дома и 12 отелей, аукцион дефицитных
  зданий, возврат домов при покупке отеля и проверка запаса при его разборке;
- залог, выкуп с 10% с округлением вверх, проценты при передаче залога;
- сделки с деньгами, участками и картами освобождения: обе стороны,
  принятие, отзыв, срок 5 минут, проверка собственности и условий при принятии;
- две перемешанные колоды по 16 карт, хранение карты освобождения вне колоды,
  переходы/ремонт/платежи каждому, новый бросок для предприятия по карте;
- тюрьма, штраф/карта/дубль, третий неудачный бросок, три дубля подряд;
- нехватка денег с возможностью залога, продажи и переговоров, банкротство
  перед игроком или банком, наследование залогов, аукционы банковского имущества;
- победа последнего небанкрота, просмотр результата, новая партия с новой
  готовностью оставшихся участников.

Рента начисляется автоматически сервером. Бесплатная стоянка не выдаёт деньги,
налоги не образуют джекпот, кредиты/передача построек и отрицательные игровые
деньги не предусмотрены. В аукционе игроки по кругу повышают ставку либо
выходят из текущих торгов; победитель платит последнюю цену. Нет секундного
таймера, принудительно покупающего участок или принимающего сделку за человека.

Для сверки поля, цен, ренты и карточек использована открытая классическая
реализация [intrepidcoder/monopoly](https://github.com/intrepidcoder/monopoly),
в частности описание правил и данные классического издания. Её исходники и
изображения в приложение не копировались. Ссылка на
[инструкцию Hasbro](https://www.hasbro.com/common/instruct/monins.pdf) сохранена
как первичный источник для последующей сверки; в этой облачной среде её
загрузка была недоступна. Старые издания с выбором подоходного налога 10%
и другими карточками не смешиваются с выбранным фиксированным вариантом.

## БК, сохранение и безопасность

Игровые деньги не конвертируются в БК. По умолчанию взнос 0 БК; создатель
может задать равный взнос и 2–10 мест. Старт доступен при двух и более
участниках и готовности всех. Условия меняются только до старта, изменение
снимает готовность. Балансы повторно проверяются при старте; банк целиком
получает победитель, без комиссии. Выход во время игры означает сдачу.
Банкрот может оставаться наблюдателем и видеть итог партии.

Кошелёк, финансовая история и runtime изменяются в одной существующей
транзакции. Повторы со старой ревизией отклоняются; клиент не задаёт кубики,
порядок колод, победителя, ренту или выплаты. Сайт не выдаёт порядок колод,
а предложения сделок видят только их стороны. Приватный стол отсутствует
в чужом списке; участие в нём возможно по приглашению до старта.

Снимок сохраняет очередь ходов, аукционы, обязательные платежи, сделки,
залоги, здания и колоды. Просмотр не продлевает активность. После 8 часов
без действий незавершённые взносы возвращаются один раз, стол закрывается.
Администратор/создатель не может расформировать стол с активной партией.

## Установка после проверки и объединения PR

На сервер самостоятельно ничего не устанавливалось. Объедините PR и выберите
**полный SHA итогового коммита из `main`**, содержащего все нужные игры. Если
другой PR добавил шашки, сначала обновите ветку PR из `main` и дождитесь новых
проверок. Установщик откажется ставить старый код, теряющий уже работающие игры.

Запускать от `root` только в рабочей установке после объединения:

```bash
bash <<'BASH'
set -euo pipefail
umask 077
revision=ВСТАВЬТЕ_ПОЛНЫЙ_SHA_ИЗ_MAIN
installer=$(mktemp /tmp/monopoly-install.XXXXXX)
trap 'rm -f "$installer"' EXIT
curl -fL --max-time 60 \
  "https://raw.githubusercontent.com/Kirito63884/ST-9economic-bot/$revision/scripts/update_monopoly.sh" \
  -o "$installer"
bash "$installer" "$revision" /var/www/balance-app
BASH
```

Обёртка запускает общий проверенный установщик из того же SHA. Он сохраняет
приватный архив заменяемых файлов и проверенную SQLite-копию базы, проверяет
полноту модулей, совместимость runtime и импорт от имени пользователя сайта.
Проверяется чтение библиотеки шахмат `www-data`, включая исправление старых
нечитаемых файлов. Новых зависимостей или таблиц БД для «Монополии» нет.
При ошибке возвращается прежний код; рабочая база автоматически не заменяется.

Обычно перезапускается только `balance-app.service`. Бот перезапускается
общим установщиком только при отличии перечисленных в нём файлов БД/правил
сборов от установленной версии. Сборщики статистики и онлайна не трогаются.
`.env`, cookies и рабочие данные не включаются в комплект кода.

После установки: Ctrl+F5 → Игры → Монополия. Проверьте бесплатную партию
двумя аккаунтами, приглашение, покупку/аукцион, имущество/сделку, выход и итог.
Затем можно проверять партию с небольшим согласованным взносом.

```bash
curl -sS -o /dev/null -w 'Приложение: HTTP %{http_code}\n' http://127.0.0.1:8000/
journalctl -u balance-app.service --since '5 minutes ago' -p warning --no-pager -n 60
```

## Локальная проверка

```bash
. .venv/bin/activate
bash scripts/check.sh
python scripts/check_monopoly_browser.py --app-python .venv/bin/python \
  --chromium /usr/bin/chromium --screenshot-dir /tmp/monopoly-screens
```

Браузерный runner запускает отдельную временную SQLite и вымышленные аккаунты,
блокирует внешние запросы и не запускает Discord/сборщики. Для runner нужны
Playwright и Chromium в среде разработчика, на сервер их ставить не требуется.

Фактический результат в этой ветке: общий `bash scripts/check.sh` — **853 passed**,
код завершения 0. Chromium — две реальные браузерные сессии с мышью/касанием,
ширины 320/390/768/1280, равный взнос и итог, аукцион, строительство/продажа,
залог/выкуп и принятая сделка; ошибок JavaScript нет. Изолированная проверка
установщика прошла успешную установку и ошибки копирования, проверки зависимости,
миграции и HTTP: прежние файлы восстановлены, новые при откате удалены, рабочие
данные и сборщики не затронуты. Это локальные проверки на фикстурах.

После объединения актуальной main проверены одновременно запущенные партии
«Монополии» и русских шашек: восстановление обеих игр, независимый расчёт
банков и финансовая история. Исправления голосовых логов из main сохранены.
