# Совместимый выпуск игр и прав доступа

Ветка объединяет шахматы, подготовленные вторым разработчиком, исправления их
совместимости с морским боем, новые SVG-модели кораблей/выстрел одним нажатием и
технического администратора. Это код для ревью; рабочий сервер не обновлялся.

Сохранены обе игры в runtime, фоновых проверках, восьмичасовом закрытии столов,
административном управлении, журнале, избранном, меню и каталоге.
В морском бое модели/типы и количество палуб своего корабля видит только владелец,
сопернику выдаются результаты выстрелов. Мышь и касание стреляют сразу, прокрутка,
масштабирование и отменённый жест не стреляют. Правила ставок/ходов не менялись.

Техадмин имеет функциональные права владельца сайта. Только реальный владелец
назначает/снимает его, понижает или удаляет его профиль. После назначения нужен
новый вход; прежние ссылки и сессии не получают новые права автоматически.
Защита входа владельца сохраняет исключительность назначения. Подробности:
[TECHNICAL_ADMIN_UPDATE.md](TECHNICAL_ADMIN_UPDATE.md).

## Установка после объединения

Выберите полный SHA согласованного main и скачайте установщик именно из него:

```bash
bash <<'BASH'
set -euo pipefail
umask 077
revision=FULL_COMMIT_SHA
installer=$(mktemp /tmp/games-access-install.XXXXXX)
trap 'rm -f "$installer"' EXIT
curl -fL --max-time 60 \
  "https://raw.githubusercontent.com/Kirito63884/ST-9economic-bot/$revision/scripts/update_games_and_access.sh" \
  -o "$installer"
bash "$installer" "$revision" /var/www/balance-app
BASH
```

Установщик содержит единый whitelist кода/шаблонов обеих игр и новых прав.
Предварительно проверяются файлы, Python-синтаксис и наличие зависимых локальных
модулей. Приватная копия выбранных старых файлов и согласованная SQLite-копия
с quick_check создаются в /root/games-access-before-*. Проверяется, что новый
serializer сохраняет все существующие ключи runtime из снимка и исходников установленного сайта. Неизвестная новая игра
останавливает обновление до замены файлов.

Добавляется только закреплённая chess==1.11.2; другие зависимости не обновляются.
Для pip применяется umask 022 в отдельном процессе, чтобы библиотека была доступна
пользователю сайта; резервные копии и внешний процесс сохраняют umask 077.
Перед остановкой сайта проверяются реальный импорт от имени www-data, версия,
путь пакета и 20 начальных ходов. Если прежняя установка оставила закрытые права,
переустанавливается только эта закреплённая библиотека и проверка повторяется.
Изменение venv ограничено этой библиотекой. При откате она может остаться,
но старый код её не использует. Новые колонки is_tech_admin=false и auth_version=0
добавляются штатной миграцией, без автоматической выдачи роли или изменения денег.

После замены проверяется импорт всего main без запуска фоновых интеграций.
Перезапускается сайт; бот — если изменились модель пользователя, составы или
прежняя политика сборов. SQSTAT и игровой монитор не перезапускаются. Рабочие
.env, база, cookies и данные источников не заменяются архивом. При ошибке
возвращаются прежние файлы, новые удаляются; рабочая база поверх новых записей
других процессов не восстанавливается, добавленные колонки совместимы со старым кодом.
Прежние update_battleship_game.sh / update_chess_game.sh / update_technical_admin.sh
в этом выпуске запускают тот же единый установщик.

После установки: Ctrl+F5, бесплатные партии с двух аккаунтов, выстрел мышью и
касанием, ничья в шахматах, меню/старые игры и журнал. Владелец открывает карточку
игрока → Права доступа для назначения техадмина; назначенный пользователь входит
заново. Проверки разработки перечислены в VALIDATION.txt; настоящие Discord,
Protocol и рабочие финансовые записи при разработке не использовались.
