# Исправления игровых полей и анимации

## Поведение

- **Шахматы.** Равные квадратные клетки не зависят от фигур и высоты боковой
  панели. Координаты a–h / 1–8 видны с четырёх сторон с правильным разворотом
  для чёрных. Свободный ход обозначает контрастная точка, взятие — кольцо.
  Фокус и выбор сохраняются при одинаковом опросе; устаревший ответ после хода
  не возвращает старую позицию. Стрелки, Enter и Escape работают на доске.
  Выход из партии/сдача предупреждают о поражении и передаче банка.
- **Домино.** Горизонтальной полосы прокрутки нет. Для каждого конца выбирается
  «По столу», «Вверх» или «Вниз», затем кость ставится кнопкой либо перетаскиванием.
  Направление сохраняется в ходе и передаётся обоим игрокам. Если выбранное
  место занято или край экрана мешает, представление огибает соседние кости и
  при необходимости уменьшает масштаб; направления — подсказки раскладки,
  а не абсолютные координаты общего фиксированного экрана. На разных экранах
  геометрия адаптируется к ширине. Дубли остаются поперёк цепочки; игровых
  концов по-прежнему два. Редкий полностью замкнутый рисунок переносится в
  вертикальную цепочку без сокрытия костей. Кнопка «Компактнее» меняет масштаб.
- **Морской бой.** По новому требованию владельца после завершения боя **оба
  участника видят расстановку соперника**, включая оставшиеся целыми корабли.
  После тайм-аута/сдачи завершённую партию можно читать по прежней ссылке, пока
  стол существует; это не возвращает право хода. Посторонним, в том числе
  администратору, чтение закрытого состояния запрещено. Во время боя чужой
  флот скрыт; новый бой снова скрывает расстановку.
- **Бильярд.** Таймер не пересоздаётся при опросе. Позиция в анимации опирается
  на монотонные часы браузера, поправка времени от сети плавная. Опрос не
  перематывает шары назад; изменение часов устройства не перескакивает кадры.
- **Покер.** Для пяти общих карт и двух карт в руке заранее отведено место.
  Ширина центра не зависит от названия улицы. Открытие тёрна/ривера не сдвигает
  флоп. Летящая карта сохраняет ту же flex-геометрию, что карта на столе.
  Прокрутка/изменение размера завершает полёт на настоящем месте карты;
  устаревшая версия состояния не возвращает прежнюю раздачу.

Балансы, расчёт банков, серверная физика, таймеры игровых правил и привилегии
администраторов не меняются. Публичность флота меняется только после боя,
как явно потребовал владелец.

## Совместимость и установка

Нужен уже установленный выпуск шахмат, морского боя и техадмина (4b3d51b или
новее) с исправленным доступом библиотеки chess для www-data. Новых зависимостей,
таблиц или миграций нет. Домино сохраняет необязательные `direction` и
`placement_order` в прежнем runtime; старые цепочки продолжаются без конвертации
рабочей базы. Старая версия игнорирует дополнительные поля.

После проверки PR и объединения в main использовать **полный SHA из main**:

```bash
bash scripts/update_game_boards.sh FULL_MAIN_COMMIT_SHA /var/www/balance-app
```

Если установщик ещё не скачан на сервер, сначала получить его из того же SHA:

```bash
bash <<'BASH'
set -euo pipefail
umask 077
revision=FULL_MAIN_COMMIT_SHA
installer=$(mktemp /tmp/game-boards-install.XXXXXX)
trap 'rm -f "$installer"' EXIT
curl -fL --max-time 60 \
  "https://raw.githubusercontent.com/Kirito63884/ST-9economic-bot/$revision/scripts/update_game_boards.sh" \
  -o "$installer"
bash "$installer" "$revision" /var/www/balance-app
BASH
```

Установщик копирует только перечисленные игровые файлы, создаёт приватную
копию прежних файлов и согласованную SQLite-копию с quick_check. Затем
перезапускает только balance-app.service, проверяет восстановление сохранённых
партий/разбор шаблонов от www-data и HTTP с повторными попытками. При ошибке
возвращает прежние файлы и удаляет новые; рабочую базу поверх новых записей
не восстанавливает. Discord и сборщики не перезапускаются. После установки
нужен Ctrl+F5, на телефоне — перезагрузка страницы.

## Проверка

Общий набор: `bash scripts/check.sh`. Браузерные команды (Playwright нужен
только разработчику; зависимости сервера не меняются):

```bash
python scripts/check_chess_browser.py --app-python .venv/bin/python
python scripts/check_domino_drag.py --app-python .venv/bin/python
python scripts/check_battleship_browser.py --app-python .venv/bin/python
python scripts/check_table_animation_browser.py --app-python .venv/bin/python
```

Используются отдельные временные базы, вымышленные аккаунты и локальные ответы;
внешние запросы браузера блокируются. В бильярде тайминги дополнительно проверяются
управляемой траекторией и задержанными ответами; покерные проверки этого runner
проверяют представление карт, а не заменяют тесты серверных ставок. Мобильная
проверка — Chromium с касаниями и небольшим экраном, без физического телефона.
Установщик проверен в изолированной shell-фикстуре: успех, сбой копирования,
проверки импортов/состояния и HTTP; systemctl/runuser/сеть там подменены. Это не
установка на рабочий сервер.

Фактический результат этой ветки: **733 passed**, Ruff и shell/JavaScript
проверки прошли. Все четыре браузерные команды выше завершились успешно;
ошибок JavaScript не зарегистрировано. Проверены шахматные клетки/координаты
на ширинах 320–1280 px, полный набор 28 костей домино без пересечений,
победа/перезагрузка/рематч морского боя, задержанные ответы бильярда и сдвиг
часов устройства на 30 секунд, раздача и слоты общих карт покера на 1280/390 px.
Два предупреждения общего набора относятся к прежним audioop и Starlette/httpx.
