# Морской бой: памятка игрока

Откройте **Игры → Морской бой**. Игра на двоих: нужно потопить весь флот соперника.

## Приглашение и ставка

Создайте стол: задайте одинаковый взнос каждого и время на выстрел.
Для бесплатной игры укажите **0 БК**. Закрытый стол доступен по ссылке;
открытый виден в лобби. **Пригласить друга** копирует ссылку комнаты.
Друг открывает её и нажимает **Присоединиться**.

Максимальная ставка — меньший из ваших балансов. Остальные игроки сайта
на предел не влияют. Если сумма после входа соперника слишком большая,
создатель снижает её в **Условиях стола**. **Поставить максимум** заполняет
доступный предел, затем нужно применить условия. Изменение условий сбрасывает
готовность обоих. При отрицательном балансе участие недоступно.

## Расстановка

Флот: **4, 3, 3, 2, 2, 2, 1, 1, 1, 1** палуб — десять кораблей.
Они прямые, горизонтальные/вертикальные, не касаются даже углами.

**Авторасстановка** сразу сохраняет случайный флот. Для ручной расстановки
выберите размер, направление и начальную клетку. Нажатие на свой поставленный
корабль удаляет его. **Очистить** очищает черновик. Когда все десять кораблей
стоят, нажмите **Сохранить флот**. Несохранённые правки при перезагрузке теряются.

После сохранения нажмите **Я готов**. Для изменения готового флота сначала
отмените готовность. Когда оба готовы, создатель нажимает **Начать бой**.
Взносы списываются в этот момент; вход и расстановка бесплатны.

## Стрельба

Первого стрелка случайно выбирает сервер. Выберите клетку на поле соперника,
затем подтвердите кнопкой **Огонь**. Одно касание клетки не стреляет.
Попадание/потопление даёт ещё один выстрел, промах передаёт ход.
Повторный выстрел в известную клетку запрещён. Вода вокруг потопленного
корабля отмечается автоматически. На телефоне доступны вкладки
**Мой флот / Поле соперника**. Целые чужие корабли скрыты до окончания.

По таймеру ход пропускается без выстрела. Три своих тайм-аута подряд — сдача;
ручной выстрел обнуляет счётчик. Для добровольной сдачи используйте выход.

## Победа и выход

Первый потопивший все чужие корабли получает **весь банк из двух взносов**.
Комиссии нет. История БК показывает чистый результат, без своего возвращённого
взноса. После боя оба флота открываются.

**Выйти со стола** до старта освобождает место без списания, во время боя — сдача
с передачей банка сопернику. Закрытая вкладка не означает немедленный выход:
таймер продолжает работать. **Ещё бой** очищает поля для новой готовности.
Создателю доступно **Расформировать** до начала и после расчёта боя.
Через 8 часов без действий стол удаляется; взносы незавершённого боя возвращаются.
Просмотр страницы срок не продлевает.
