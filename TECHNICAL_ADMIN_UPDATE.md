# Технический администратор сайта

Владелец: **Админка → Игроки → Открыть → Права доступа → Технический администратор**.
Назначенный игрок получает весь набор операций владельца сайта: кошельки, включая
баланс/имя владельца, массовые операции, награды, группы, сборы, автоматизация,
управление обычными администраторами, игры, журналы и резервные копии.
Это отдельная роль сайта; прав администратора Discord или root она не выдаёт.

Назначение, снятие, понижение и удаление профиля техадмина доступны только реальному
владельцу из ADMIN_DISCORD_ID. Сам техадмин, другой техадмин и главные администраторы
не могут обойти запрет через API, импорт или удаление профиля. Discord-синхронизация
не снимает эту роль и не архивирует такой профиль. Все изменения роли пишутся
в журнал. Никому автоматически она не назначается.

«Снять техадмина → главный» сохраняет права главного администратора. Можно отдельно
выбрать другой уровень или «Снять права» для полного снятия доступа.

После назначения нужно **войти заново**. Поле auth_version и отзыв прежних ссылок
не дают старой сессии, полученной через делегированную ссылку обычного игрока,
превратиться в сессию техадмина. Снятие полномочий проверяется на следующем запросе,
включая подтверждение уже подготовленной массовой операции.

Защита личности владельца сохранена: делегированные администраторы не получают
ссылку входа за владельца и рабочий ключ его сессии. Скачивание резервной копии
доступно техадмину; в его копии сбрасываются ключ входа и личные ссылки, данные
игроков/игр/история сохраняются. Эта граница нужна, чтобы назначение техадмина
оставалось действительно только у владельца. Вход другого техадмина также защищён.

Миграция добавляет users.is_tech_admin (false) и users.auth_version (0). Остальные
поля, балансы и уровни не меняются. Старый код совместим с добавленными колонками;
при откате они сохраняются. Рабочая база автоматически не восстанавливается.

Проверки: tests/test_technical_admin.py, общий bash scripts/check.sh и изолированный
Chromium-runner scripts/check_technical_admin_browser.py (Playwright нужен только
для разработки). Используются вымышленные профили и локальные базы; Discord и
другие рабочие источники не подключаются.

Установка после ревью из согласованного main: scripts/update_technical_admin.sh
FULL_COMMIT_SHA /var/www/balance-app. Перед заменой проверяются зависимости,
сохранение ключей runtime, приватная копия файлов и согласованная SQLite-копия.
После замены выполняется добавочная миграция и импорт main без запуска фоновых
задач. Перезапускаются сайт и бот, использующий модель пользователя и составы.
Сборщики SQSTAT и игрового онлайна не перезапускаются.

Для общего выпуска шахмат, моделей морского боя и техадмина используйте
`scripts/update_games_and_access.sh FULL_COMMIT_SHA /var/www/balance-app`.
Прежние три точки установки перенаправляют в этот единый проверенный комплект,
чтобы общий main, модели пользователей, JS-partials и зависимости совпадали.
Подробнее: [GAMES_ACCESS_UPDATE.md](GAMES_ACCESS_UPDATE.md).
